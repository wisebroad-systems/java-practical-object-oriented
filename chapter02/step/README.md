# 第2章 step：追加と確定の操作を導入する

第2章の途中段階のコードです。注文に`addItem()`と`confirm()`を導入し、確定後の追加を拒否するようにしました。ただし、`getItems()`はまだ内部のリストをそのまま返しています。

## 実行する

このディレクトリ（`chapter02/step`）で、次のコマンドを実行します。

```powershell
javac -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main
```

コンパイルされるファイルは、`MenuItem.java`・`Order.java`・`Main.java`の3つです。

## 期待する結果

```text
確定済み：true、合計：2000円
確定済み：true、合計：0円
```

## この段階で成り立つルール

- メニュー項目は名前と価格を持ちます。価格は0円以上で、負の価格は作成時に拒否します。
- 名前が`null`・空文字・空白だけのメニュー項目は、作成時に拒否します。
- 料理がない注文は確定できません。0円の料理だけの注文は確定できます。
- 確定済みの注文は、もう一度確定できません。
- 確定後は、`addItem()`で料理を追加できません。
- `null`の料理は追加できません。
- 拒否した操作の後も、注文の内容と状態は変わりません。

## 意図的に残している問題

この段階は、次の章や段階で直す前の状態です。次の問題は、不具合ではなく、本文で考えるための題材として残しています。

- `getItems()`が返したリストを`clear()`すると、確定済みの注文の中身を消せてしまいます（実行結果の2行目で、合計が0円になっています）。
