# 第2章 start：第1章の終了時点

第2章の開始時点のコードです。第1章の終了時点（`chapter01/end`）と同じ内容です。

## 実行する

このディレクトリ（`chapter02/start`）で、次のコマンドを実行します。

```powershell
javac -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main
```

コンパイルされるファイルは、`MenuItem.java`・`Order.java`・`Main.java`の3つです。

## 期待する結果

```text
会計：2000円
注文確認：2000円
```

## この段階で成り立つルール

- メニュー項目は名前と価格を持ちます。価格は0円以上で、負の価格は作成時に拒否します。
- 名前が`null`・空文字・空白だけのメニュー項目は、作成時に拒否します。
- 注文は、自分の料理の価格を足して合計を求めます。

## 意図的に残している問題

この段階は、次の章や段階で直す前の状態です。次の問題は、不具合ではなく、本文で考えるための題材として残しています。

- 注文には「確定」という状態がなく、確定後は内容を変更できないというルールを表せていません。
- `getItems()`が注文の内部のリストをそのまま返すため、外から注文の中身を変えられます。
